Syntax

nc {options} {ip} {port}

Options

-l : listening mode -p : specify port number -n : no DNS resolutio -v/-vv: verbose/very verbose -k: keep listening after client disconnection

Examples: netcat as client

nc 10.10.10.10 80

GET / HTTP/1.1
host: netcat

Examples: netcat as server

nc -lvnp 1234

GET / HTTP/1.1
host: netcat
