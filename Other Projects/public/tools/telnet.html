Definition

I can use Telnet to test connection toward whatever TCP unencrypted server. Some examples are:

  • Echo server (TCP/7): echoes back everything sent.
  • Daytime server (TCP/13): replies with Daytime
  • Web HTTP Server (TCP/80): serves web pages

Syntax

telnet {options} {ip|domain} {port}
