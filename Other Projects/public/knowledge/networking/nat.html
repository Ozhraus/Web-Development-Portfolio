Network Address Translatio (NAT)

NAT is a technology that allows to bind multiple private IP addresses to one single public IP addresses. The sense of this technology is that at the very beginning of Internet, the IP addresses schema were divided in Class A, B, C, D, E. This introduced the problem of addresses exhaustion. NAT comes into play because it attempts to workaround the problem, trying to bind LAN's IP address (Internal Network) with a single public IP (External Network). Each response is turned back because a socket pair (IP:port) is used to map the Internal to the External network and vice versa.
