The TCP/IP Model

TCP/IP model was developed by DoD. It's an implementation model adopted to actually enforce semantic and grammatic of the general language used within a computer Network.
The model compress the 7 OSI layers into 4, optimizing the processing of the information by reducing its complexity design. That is, a lot of unfolded layers can be actually folded together in a way that the global networking operation can still be successfull. Let's take a look:

  1. TCP/IP Layer 1 (Network Interface) corrisponds to OSI Layer 1, 2 (Physical and Data Link)
  2. TCP/IP Layer 3 (Network) connect to OSI Layer 3 (Network)
  3. TCP/IP Layer 4 (Transport) binds to OSI Layer 4 (Transport)
  4. TCP/IP Layer 5 (Application) corrisponds to OSI Layer 5, 6, 7 (Session, Presentation and Application)
