Router & Routing: how does it work?

As we saw during our networking lesson routing occurs at the very beginning of packet transmission. That means, each packet after being encapsulated need to be roted toward its destination. Switch provide L2 routing, while router Layer 3 routing. In this section we are taking care of L3 Routing.

Layer 3 Routing

Layer 3 routing is accomplished by inserting Layer 3 informations, like sender and receiver IP, and by sending the packet through its default gateway, aka the Router. Router is an intermediary device that is responsible for Layer 3 addressing. We can discriminate different cases:

  • Static routing: the network administrator sets static routes within the Router internal table. This allow a manual handling of the routing, but making it prone to problems like wrong routes, wrong priorities, weak optimization, etc
  • Dynamic routing: done thanks to routing algorithm that allow route selection.
    • OSPF (Open Shortest Path First): exchange of routing/topology informations with other neighbours for finding the best route based on shortest path.
    • EIGRP (Enhanced Interior Gateway Routing Protocol): Cisco proprietary. Allow to exchange network informations with others router and evaluate the one with low cost.
    • BGP (Border Gateway Protocol): helps with ISPs routing information exchange.
    • RIP (Routing Information Protocol): exchange of network information based on hops.
