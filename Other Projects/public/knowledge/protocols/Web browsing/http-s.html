HyperText Transfer Protocol

HTTP is a web protocol that allows to transfer HTML pages, images, resources via HTTP call. It works onn TCP/80 or TCP/443 with its encrypte version; some of the HTTP calls called methods, are:

  • GET: request a specific resource
  • POST: pulling a resource
  • PUT: update a resource reference
  • DELETE: remove a resouce

HTTP Servers

Main selection for HTTP Servers are:

  • IIS Server: MS proprietary
  • Apache: open source
  • nginx: open source
