Dynamic Host Configuration Protocol (DHCP)

Dynamic routing information allocation for hosts within a LAN; these informations are: IP, default gatway, DNS server, DHCP server, leasing time, relay address (optional).

Ports

UDP/67 (server)
UDP/68 (client)

How does it work

Exchange of 4 messages:

  1. DHCPDISCOVER to 255.255.255.255/ff:ff:ff:ff:ff:ff
  2. DHCPOFFER
  3. DHCPREQUEST
  4. DHCPACK/NACK
Before the IP allocation, host is served with 0.0.0.0 IP address; in case of failed allocation host is served with APIPA address 169.254.0.0/16.
