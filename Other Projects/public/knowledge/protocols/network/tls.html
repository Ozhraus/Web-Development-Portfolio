Transport Layer Security (TLS)

Encryption protocol that provide Confidentiality, Integrity and Authenticity that allows a secure exchange of the informations among server without been eavesdropped.
It is used by itself or binded to other protocol to realize a secure exchange of the data. Some examples are DoT, HTTPS, MQTTS, SIPs, SMTPs, and more over. It's a Layer >4 protocol, overcoming its previous version Secure Socket Layer (SSL).
