Internet Control Message Protocol (ICMP)

Protocols that helps with network trobleshooting. It's used by ping and telnet

Ports

Not USED: is a Layer3 protocol.

How does it work

With ping it works via an exchange of 2 messages:

  1. ICMP echo/type 8
  2. ICMP echo reply/type 0

With telnet an interesting field within ICMP is Time To Live (TTL), that defines the maximum hop a packet can pass through. If TTL = 0, packet is dropped and a ICMP Time Exceed Message (ICMP Type 11) is received.
