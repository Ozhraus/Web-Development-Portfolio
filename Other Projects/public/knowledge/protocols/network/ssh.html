Secure Shell (SSH)

Application layer encrypted protocol whose aim is providing a remote shell for allowing Remote Code Execution within a system on TCP/22. It provides:

  • Authentication: password-based, certificate-based, key-based
  • Confidentiality: thanks to encryption
  • Integrity: thanks to HMAC technology
  • Tunneling: thanks to encryption
  • X11 Forwarding: allow use of GUI while connecting to unix-like system

SSH Options

Below a brief overview of SSH options:

  • -X : provide X11 Forwarding feature
