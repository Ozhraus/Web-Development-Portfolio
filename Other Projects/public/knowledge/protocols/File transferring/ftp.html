File Transfer Protocol

FTP is a protocol that allows to exchange file resource among servers that are available for an FTP connection. It uses port TCP/21 for connection initialization and TCP/20 for the data exchange. Secure version of the protocol are:

  • SFTP: use TCP/22 (SSH) for an encryptd data exchange
  • FTPS: FTP over TLS using TCP/990

FTP Commands

Bellow a brief overview over the commands used during a FTP session:

  • USER: input username
  • PASS: input password
  • RETR: DL from server to client
  • STOR: upload from client to server
  • STAT: provide additional info
  • SYST: show system type
  • PASV: enter passive mode
  • ls: list directory
  • type {mode}: switch to ascii or passive mode depending of the actual operation that need to be executed. Some mode example are: active/passive, binary/ascii.

FTP operation modes

FTP use different operation modes depending on what we need to ccomplish:

  • Active: client initialize connection to TCP/21 and servers turns back data connection from TCP/20 to the desired client destination port ➡️ Data is sent to a separate channel from the server
  • Passive: client initialize directly data connection to the server TCP/20, by initially connecting to TCP/21, then receiving back the data port to which connect ➡️ Data is sent to a separate channel from the client
  • ASCII: used for transferring text base file; used to increase intersystems compatibility.
  • Binary: used for non-text files like .jpg, .gif, .mp3, .zip.

Anonymous login

It's possible to test FTP resilience by tryig initializing an anonymous session by issuing "anonymous" as username and providing blank password secret.
