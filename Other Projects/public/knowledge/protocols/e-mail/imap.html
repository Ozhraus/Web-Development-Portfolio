Internet Message Access Protocol (IMAP)

e-Mail protocol used to DL while leaving a copy of the message within the MDA server. It uses TCP/143 or TCP/993 for its secure version

IMAP Commands

Below a brief overview of IMAP commands:

  • LOGIN {username} {password}: user athentication
  • SELECT {mailbox} : select mailbox folder
  • FETCH {mail number} {data name}: request message number, with its header and/or body ➡️ FETCH 4 body[]
  • MOVE {sequence} {mailbox}: move message to another mailbox
  • COPY {sequence} {data name}: copies email to another mailbox
  • LOGOUT: close IMAP session.
