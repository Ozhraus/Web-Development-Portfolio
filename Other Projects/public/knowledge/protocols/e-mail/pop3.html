Post Office Protocol 3 (POP3)

e-Mail protocol used to DL w/o leaving a copy of the message within the MDA server. It uses TCP/110 or TCP/995 for its secure version

POP3 Commands

Below a brief overview of POP3 commands:

  • USER {username}: user identification
  • PASS {password}: authentication
  • STAT: request message numbers and total size
  • RETR {message number}: retrieve a specific email
  • DELE {message nmber}: delete a specific email
  • QUIT: close POP3 session.
