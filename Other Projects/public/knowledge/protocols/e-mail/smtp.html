Simple Mail Transfer Protocol

e-Mail protocol that allows uploading, aka sending, e-mail via TCP/25 or TCP/465 or TCP/587 to a relay agent for the message.

SMTP delivery process

Sending email works as follow:

  1. Sender (MUA) send e-mail to a Message Submission Agent (MSA) by connecting TCP/587 (with STARTTLS query) for a secure channel.
  2. e-Mail is delivered to a Mail Transfer Agent (MTA) for understanding receiver location (within or otside the actual domain?) thanks to a MX lookup
  3. Once figured out the domain location of the receiver (via TCP/25 normally used for server-server transmission), the relay agent forward it to the actual domain if it's the same or to other forwarder MTA agents charged of forwarding untill reaching the authoritative one.
  4. Once arrived to the desired domain, e-mail is delivered to Mail Delivery Agent (MDA) server waiting to get retriev by receiver.

!WATCH OUT! MTA and MSA or MTA and MDA can be tied into 1 entity.

SMTP Commands

Below a brief overview of SMTP basic commands:

  • HELO | EHLO: SMTP session initialization
  • MAIL FROM: specify sender address
  • RCPT TO: receiver address
  • DATA: data message
  • . : put on a line by itself means End Of Message.
